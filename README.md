# Karel the Robot

This is my work from Karel weeks of COSC 10001 at TCU. Karel is a robot that can move around a world and perform basic commands.

## How to Run

Open the Karel folder in IntelliJ and press the green Run button. On Windows, you can also use `run.ps1`, and on macOS you can use `run.sh`.

## What I Learned

- Karel does not have a `turnRight()` command, so I can create one using three `turnLeft()` calls.
- I learned how to use loops and conditional statements to make Karel perform tasks.
- I learned how to use Git and GitHub to save and share my programming work.
